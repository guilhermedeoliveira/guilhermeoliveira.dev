A personal site with projects, essays, notes, RSS, search, and strong design does not need to be a server application.

Static sites win because they remove entire classes of operational concerns. No runtime database. No server cold start. No auth boundary. No production backend to babysit.

## Where dynamic behavior belongs

Interactivity should earn its place. Search can be static. Filters can be client-side. Writing can live in Git. Deploy previews can happen at the edge.

When a site finally needs dynamic features, they can be added deliberately.

## The default

The default should be a fast document system with a beautiful interface.
