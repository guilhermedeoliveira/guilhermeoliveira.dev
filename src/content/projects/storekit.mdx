## Context

storekit packages the transactional outbox pattern for teams that already trust their relational database and want fewer moving pieces in their event pipeline.

## Trade-off

It deliberately avoids becoming a queue. That keeps the library understandable, but it means operators still need to own backpressure and worker behavior.
