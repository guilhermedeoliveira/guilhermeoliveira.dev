Storekit helps applications publish domain events safely after database
transactions commit. It keeps the outbox pattern compact enough to understand
and explicit enough to operate.

## Reliability path

The library focuses on predictable polling, clear lock behavior, and simple
schema primitives that can be inspected without special tooling.
