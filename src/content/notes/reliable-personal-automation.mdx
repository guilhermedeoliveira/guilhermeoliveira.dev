The tempting version of personal automation is magical. The durable version is boring.

For workflows that touch documents, calendars, bank statements, or health records, the right goal is not autonomy at any cost. The right goal is repeatability with inspection points.

## Rules I keep coming back to

Use plain files where possible. Log every operation. Prefer deterministic parsing before language model interpretation. Make pending work visible. Keep the raw source lifecycle clear.

The system should be useful when it works and understandable when it fails.

## The real interface

The real interface is often not a dashboard. It is a command, a log entry, and a file that can be reviewed later.
